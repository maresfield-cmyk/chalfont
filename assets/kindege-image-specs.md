# Kindege (Aviator) — Image Specs & Prompts

Palette reference: the Aviator in-game screenshot and logo (uploads/av-01.jpg, uploads/images.jpeg) — near-black background (#0A0A0A, matches ChezaBora's ink), a red flight-path/plane in a red-to-maroon gradient (#E8281A → #7A0F0A), white multiplier numerals, and small neon accent chips (green/cyan/purple). ChezaBora's existing yellow (#FCD116), green (#1EB53A) and blue (#00A3DD) stay for UI chrome (buttons, badges) — red is the new accent reserved for Aviator/Kindege imagery only, so it doesn't compete with the site's CTA color.

Style direction for all 7: flat vector illustration, bold thick outlines, limited palette (black/red/white + one ChezaBora accent), no photorealism, no text baked into the image (headlines are HTML). Safari/Tanzania motifs stay subtle (a Kilimanjaro silhouette, warm sunset tone) so they don't fight the red/black Aviator identity.
